===============================================================

This is the one question the table invites, because the TCS
records defects as confirmed against three of these four test
cases:

              DEF-F6-03 (Wish list control)
              DEF-F1-05 (Refer a friend control)

  TC-01-002   DEF-F1-01 (Breadcrumb path accuracy)
              DEF-F1-02 (Product parent collection)

  TC-01-003   None

  TC-01-004   DEF-F1-04 (RSS feed icon destination)
              DEF-F1-06 (Footer Sauce link destination)

All four procedures still report Pass. That is intentional and
follows the TPS, which the team designated as the governing
document for execution in this cycle.

Where a defect is already confirmed, the TPS words the matching
step observationally rather than as an assertion. TC-01-001 #6
reads: "Click the Wish list navigation link. Record the URL shown
in the address bar after the click, including any fragment
appended to it, and record whether any page, panel or overlay is
displayed." It directs the tester to capture what happens, not to
judge it against an expected result. The frozen TPS also notes
that this step discharges REQ-F6-08 and DEF-F6-03.

So the Pass means: the procedure executed and recorded what the
TPS asked it to record. It does NOT mean the store behaved
correctly at those steps. The defects remain confirmed in the
Defect Log and the evidence from these runs supports them.

FOR THE TEST DESIGNERS: the TCS states definite expected results
for the same steps. TC-01-001 #6 expects "The Wish list page is
displayed, listing saved items or showing an empty-wishlist
state", which the store does not do - independently confirmed
during FN-06 execution, where the same control was found to be a
dead in-page anchor with no wishlist page in existence at all.
Under the TCS wording, TP-01-001, TP-01-002 and TP-01-004 would
each report Fail. The two documents give different verdicts for
the same behaviour. Worth aligning before the next cycle, and
worth checking whether FN-02 and FN-03 diverge the same way.
